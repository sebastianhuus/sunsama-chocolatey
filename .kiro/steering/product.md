# Product Overview

This is a Chocolatey package repository for Sunsama, a digital daily planner application that helps users maintain work-life balance and stay focused.

## Package Details

- **Package Name**: sunsama
- **Upstream**: Sunsama Desktop (https://www.sunsama.com/desktop)
- **Distribution**: Chocolatey Community Repository
- **Maintenance**: Manually updated package with automation support

## Purpose

Provides Windows users with an easy way to install and update Sunsama via the Chocolatey package manager. The package downloads the official Sunsama installer and installs it silently.
